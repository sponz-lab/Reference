입고 검수 설치

매장에서 할 일은 3분이면 끝납니다. 프로그램을 내려받거나 계정을 만들 일은 없습니다.

1 휴대폰에 담기

휴대폰 기본 카메라로 아래 QR을 비추고, 뜨는 링크를 누르세요.

홈 화면에 추가해 두면 앱처럼 열립니다.

아이폰 — 공유 버튼 → 「홈 화면에 추가」
안드로이드 — 점 세 개 → 「홈 화면에 추가」

2 매장 PC에 북마크 두 개 걸기

아래 초록 버튼을 북마크바로 끌어다 놓으세요. 누르는 것이 아니라 끌어다 놓는 것입니다.

북마크바가 안 보이면 Ctrl + Shift + B

리스트 가져오기 회사 시스템의 입고·반품 리스트를 검수 프로그램으로 가져옵니다
반품 입력하기 반품 검수가 끝나면 박스번호·처리수량을 회사 시스템에 채워 줍니다
이 북마크는 매장 PC 크롬에만 걸면 됩니다. 휴대폰에는 필요 없습니다.

3 아침에 쓰는 순서

  1. PC에서 회사 시스템에 매장 아이디로 로그인하고 전표번호로 조회
  2. 북마크 리스트 가져오기 → 검수 프로그램이 열리며 리스트가 들어감
  3. 검수 시작 → 화면에 참여 QR이 뜸
  4. 직원들은 휴대폰 기본 카메라로 그 QR을 찍어 합류
  5. 각자 찍으면 수량이 실시간으로 합쳐집니다
백화점처럼 소리를 낼 수 없는 곳에서는 휴대폰이 진동과 화면 색으로 알려 줍니다. 블루투스 스캐너를 연결하면 화면 키보드 없이 그대로 찍을 수 있습니다.

4 물류 반품할 때

  1. 매장반품관리에서 반품을 조회한 목록 화면에서 리스트 가져오기 (반품코드를 누를 필요 없습니다)
  2. 상자마다 포장 박스 번호를 바꿔 가며 담고 스캔
  3. 끝나면 박스별 반품 리포트를 인쇄해 상자에 동봉
  4. 같은 화면의 전산 입력용 복사 → 회사 시스템 목록에서 반품 입력하기
  5. 박스번호·처리수량이 채워지면 임시저장과 반품처리중은 직접 누르세요

5 매장간 이동(RT)할 때

  1. 매장관리 → 매장RT관리에서 기간과 구분(매장출고 / 본사요청RT)을 지정해 조회
  2. 그 화면에서 리스트 가져오기 — 받는 매장이 여럿이면 어느 매장 것인지 고르는 창이 뜹니다
  3. [보냄]이 우리가 포장해 내보낼 것이고, [받음]은 다른 매장이 우리에게 보내는 것입니다
  4. 받는 매장 한 곳씩 담으세요. 상자가 섞이지 않습니다
  5. 끝나면 박스별 리포트 — 상자마다 받는 매장이 크게 찍힙니다
물류 반품과 매장간 이동은 종이가 다릅니다. 물류 반품은 「반품 포장 리스트 · 물류 확인」, 매장간 이동은 「이동 포장 리스트 · 받는 매장 확인」으로 나옵니다.

문제가 있으면 도봉산점으로 알려 주세요.
