입고 검수 프로그램 — 매장 설치 (3분)
====================================

내려받거나 깔 프로그램은 없습니다.
매장 PC 크롬에 북마크 네 개를 넣고, 휴대폰으로 주소를 여는 것이 전부입니다.


[1] 매장 PC — 북마크 한 번에 넣기
---------------------------------

1. 크롬 주소창에  chrome://bookmarks  입력 후 엔터
2. 오른쪽 위 점 세 개(⋮) → "북마크 가져오기"
3. 이 폴더의  북마크모음.html  선택
4. 북마크바에 "입고 검수" 폴더가 생깁니다
   (북마크바가 안 보이면  Ctrl + Shift + B)

들어가는 북마크 네 개
   0. 설치와 사용법      - 자세한 안내 페이지
   1. 검수 프로그램      - 검수 화면 열기
   2. 리스트 가져오기    - 회사 시스템의 입고·반품·RT 리스트를 끌어옴
   3. 전산에 입력하기    - 검수 결과를 회사 시스템 칸에 채움

엣지도 같은 방법입니다.  edge://favorites  → 가져오기 → HTML 파일


[2] 직원 휴대폰
---------------

아래 주소를 열고 "홈 화면에 추가" 하면 앱처럼 쓸 수 있습니다.

   https://sponz-lab.github.io/Reference/

더 쉬운 방법: PC에서 북마크 "0. 설치와 사용법" 을 열면
QR이 나옵니다. 휴대폰 기본 카메라로 찍으면 바로 열립니다.


[3] 아침에 쓰는 순서
--------------------

1. 회사 시스템에 매장 아이디로 로그인 → 상품입고관리에서 전표 조회
2. 북마크 "리스트 가져오기"
3. 검수 시작 → 화면에 참여 QR이 뜸
4. 직원들은 휴대폰 카메라로 그 QR을 찍어 합류
5. 각자 스캔 → 수량이 실시간으로 합쳐짐

반품과 매장간 이동도 같은 방식입니다.
자세한 내용은 북마크 "0. 설치와 사용법" 에 있습니다.


[4] 자주 막히는 곳
------------------

* 북마크를 눌렀는데 "리스트 화면이 아닙니다"
  → 회사 시스템에서 리스트를 조회한 화면에서 눌러야 합니다

* 상세 창이 안 열림
  → 주소창 오른쪽의 팝업 차단 표시를 눌러 허용으로 바꾸세요

* 휴대폰에서 카메라가 안 켜짐
  → 처음 한 번 "카메라 사용 허용" 을 눌러야 합니다

* 블루투스 스캐너를 쓰면 화면 키보드가 안 올라옴
  → 스캐너가 키보드로 잡혀서 그렇습니다. 스캐너를 끄면 돌아옵니다
